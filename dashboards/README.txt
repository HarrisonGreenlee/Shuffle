TO OPEN A STATISTICS DASHBOARD:

1. If zipped: extract the zip file. The dashboard will not open correctly from a zip viewer.

2. Be careful not to separate the dashboard.html from supporting image files. The images will not render on the page if it is moved.

3. Open the dashboard.html file by double clicking on it. This will bring up a statistics dashboard that can be viewed using your web browser.


TO SHARE A STATISTICS DASHBOARD:

1. Zip the entire dashboard folder. The dashboard.html will not render correctly on its own.

2. Send the file along with these instructions.
